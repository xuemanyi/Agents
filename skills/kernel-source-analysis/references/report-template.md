## 证据交接约定

- 事实 ID 在同一次交付中保持稳定。复用证据时保留基线、路径、行号、符号、条件和等级，不把静态推断升级为已确认。
- 源码或配置变化后需要重查受影响事实；不能跨版本复用旧行号。
- 交接对象是证据与未决问题，不是缺陷结论、设计规格或风险评分。后续 Skill 是否适用、是否可用和是否获授权，由后续任务决定。
- 模板中的占位符用于生成实际报告；交付时替换为真实内容，未知处直接说明，不保留看似有证据的虚构示例位置。
